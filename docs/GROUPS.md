# 科目群組與本機資料

版本：0.9.0。群組只處理科目管理，不改變教材身分、生成上下文、快取或模型排程。

首頁提供新增、重新命名、移除、群組篩選、個別與批次移動。搜尋後的「全選目前結果」只選目前篩選結果；批次指定群組後送出。每份教材最多一個群組，移除群組使其回到未分組，保留原 PDF、閱讀位置、講稿、問答與概念圖。群組內匯入會歸入目前科目；浮動書庫可依群組篩選。

Store 在書庫根目錄以 library.json 保存 groups 與 memberships（教材 SHA-256 → 群組 ID）。先原子寫入成功才替換記憶體狀態；舊書庫缺少此檔案時直接視為全部未分組。群組名稱去除首尾空白，長度 1–60 字，NFKC 與大小寫正規化後不可重複；最多 200 組，單次移動最多 1000 份且全部教材與群組須存在。備份／搬移時包含 library.json。

IPC createGroup / renameGroup / deleteGroup / moveBooks 受既有來源驗證保護，成功只發出狀態變更，不喚醒 Engine。教材刪除同時清理其群組歸屬；同一 PDF 內容仍由 SHA-256 識別，不因群組建立複本。

目前不提供巢狀群組、多重標籤、跨 PDF 搜尋語義或跨教材概念生成。這些功能需另行決定來源範圍與生成規則。
