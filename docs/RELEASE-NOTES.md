0.8.0 新增概念複習地圖。

- 全書解析、脈絡與逐頁講稿完成後，在「概念複習」手動按生成；開啟或切換不自動呼叫模型。
- 全幅互動畫布：主題展開、搜尋縮寫／全名、類型篩選、拖曳、縮放與聚焦關係。
- 術語、公式、參數單位與條件整理；節點及關係來源可跳回 PDF。
- 地圖與視角保存在本機，支援暫停／手動續作；重新產生失敗保留舊圖。
- 保留既有閱讀、手動生成與自動更新行為。

下載 **Study-Project-Setup.exe** 安裝一次，之後從桌面或開始功能表的 Study Project 開啟。

- 安裝版啟動後會自動檢查新版、背景下載；完成後到設定按「重新啟動並更新」。
- 更新先保存教材與學習紀錄，再安裝重開；生成仍需手動繼續。
- 舊可攜版須手動下載安裝一次，才能使用後續的 App 內更新。教材搬移請參閱 README。
- Study-Project-Windows.exe 為可攜版，不支援自動更新。
- 程式尚未簽章，Windows 警告仍可能出現。
